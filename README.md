# BMI calculator project 

## Description
The BMI Calculator is a mobile application that allows users to calculate their body mass index (BMI) based on their height and weight. The app provides a simple and intuitive interface for users to input their information and receive their BMI result, along with a classification of their weight status.

## Installation
1. Install the Flutter SDK
2. Clone the project repository
3. Install the project dependencies using flutter pub get
4. Run the app using flutter run

## Usage
1. Launch the BMI Calculator app on your mobile device or emulator.
2. Enter your gender and your height (in centimeters) and weight (in kilograms) and your age.
3. Tap the "Calculate" button to see your BMI result and weight status classification.
4. The app will display your BMI value and indicate whether your weight is in the underweight, normal, overweight.
